  • 担任中国计算机学会及中国图象图形学会会员，连续多年担任多媒体领域顶级国际会议ACM MM程序委员会成员，ACM MM 2023多模态信息检索Workshop的共同组织者, 担任SCI一区期刊Information Processing & Management客座编辑，担任IEEE TPAMI / TIP / TMM / TCSVT / TNNLS / TCYB / TGRS / TASE / SP等40多种国际知名期刊和会议的审稿人，获得SCI期刊Neurocomputing及Journal of Visual Communication of Image Representation的优秀审稿人称号。

研究方向

  • 短视频多维内容理解与分析：课题研究以短视频多模态表征学习与融合机制为主轴，聚焦于短视频内容的深层语义理解与精准分发管理两个核心维度，研究内容涵盖短视频记忆度预测、短视频多标签分类、短视频情感分析、短视频个性化推荐等多个核心技术。

  • 多源图像增强与鲁棒异常检测：课题研究立足于复杂环境场景下视觉信息的质量提升与异常模式的精准识别两个关键维度，研究内容涵盖低照度图像增强、水下异常检测、多源图像融合、工业异常监测。

  • 医学影像处理与精准诊疗：课题研究针对临床医学和人工智能和深度交叉应用，旨在通过多模态感知与表征辅助医疗决策，研究内容涵盖术后疼痛评估、低造影剂图像增强、精准营养推荐、退行性神经疾病筛查及康复。

  • 应用导向的多媒体系统工程：致力于多模态数据挖掘与智能分析算法的落地实践，提供解决行业痛点的工程方案，与中央广播电视总台、中国移动通信集团设计院、中电信人工智能科技、中兴通讯、宝盈智能等知名机构构建长期稳定的合作关系。
